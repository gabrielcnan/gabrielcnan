## Método

**Consultar → Planejar → Executar → Validar → Registrar**

- Definir escopo e critérios antes de agir.
- Separar resultados observados, relatos, simulações e hipóteses.
- Preservar a privacidade, a integridade dos dados e o menor privilégio.
- Documentar falhas e próximos passos, sem atribuir competências não demonstradas.

Este repositório contém documentação de portfólio, não o código-fonte operacional dos projetos. Não inclui logs brutos, credenciais ou configurações privadas. Os materiais foram elaborados com assistência de IA e revisão humana em andamento.
